# The-software-designer-note

软件设计师（软考中级）的备考笔记。复习时把考纲拆开，按专题整理成一篇篇笔记，哪块薄弱翻哪篇。内容以教材和考纲为依据，考前拿来查漏补缺正合适。

目前覆盖的专题：

- 组成与系统：[计算机组成体系与构成](./【软考】计算机组成体系与构成.md)、[操作系统](./【软考】操作系统.md)、[信息安全](./【软考】信息安全.md)
- 语言与规范：[程序设计语言基础](./【软考】程序设计语言基础.md)、[知识产权与标准化](./【软考】知识产权与标准化.md)
- 数据：[数据结构](./【软设】数据结构.md)、[数据库系统](./【软设】数据库系统.md)、[计算机网络](./【软设】计算机网络.md)
- 方法与管理：[面向对象基础](<./【软设】 面向对象基础.md>)、[系统开发基础](<./【软设】 系统开发基础.md>)、[项目管理](./【软设】项目管理.md)

发现错误或想补充，欢迎提 issue。

## English

Study notes for the Software Designer exam (China's Ruankao, intermediate level). The syllabus is broken down into one file per topic — operating systems, data structures, databases, networking, OOP, project management, and more — so you can review whatever needs work. Written against the official textbook and syllabus; handy for gap checking before the exam.

Corrections and additions are welcome via issues.
